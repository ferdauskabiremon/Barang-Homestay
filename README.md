# Barang Village Homestay — React Prototype

A homepage prototype for baranghomestay.com, restructured around three
upsell sections: Homestays, Experiences/Day Trips, and Cooking Classes.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

Content is sourced from the live baranghomestay.com site, Airbnb listings,
and GetYourGuide tours. Hero/gallery imagery is Unsplash placeholder
photography pending real village photos.
